### **Frontend**
cd client          # Navigate to React frontend
npm install        # Install dependencies
npm start          # Start development server

## **Features**

- Display all TODOs
- Add, edit, delete TODOs
- Mark TODOs as done/undone
- Form validation for required fields
- Handles loading and error states
- Modular components with clean structure

### Asusmptions & Limitations

- Assumptions & Limitations
- No user authentication implemented yet
- All TODOs are global (not user-specific)
- Animations are not yet implemented
- Error handling relies on simple alerts or messages
